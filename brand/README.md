# Haven logo pack

The Haven mark: a little lit house on an island at dusk. The sun's reflection on the
water is drawn as rows of data, and a small constellation of connected stars stands for
the smart home. Open `contact-sheet.html` in a browser to see every file on light and dark.

Everything here is generated by `build-pack.mjs` from one definition of the art. To change
the logo, edit the art in that script and run it from the repo root:

```bash
node brand/build-pack.mjs
```

It rewrites `svg/`, `png/`, `web/` and `android/`, and copies the web icons into
`web/public/`. Don't edit the generated files by hand.

## Two versions of the art

- **Full** (`haven-icon*`): the whole scene. Use it at 64px and up.
- **Small** (`haven-icon-small*`): a simplified scene (sun, house, two reflection bars) that
  stays readable at 48px and below. Favicons, browser tabs and the topbar use this one.

## What to use where

| Need | File |
|---|---|
| Master artwork | `svg/haven-icon.svg` (square), `-rounded.svg`, `-circle.svg` |
| Small sizes (48px and below) | `svg/haven-icon-small.svg`, `-small-rounded.svg`, `-small-circle.svg` |
| One colour (print, stamps, themed icons) | `svg/haven-icon-mono.svg` (black; recolour it) |
| PNG at a fixed size | `png/square/`, `png/rounded/`, `png/circle/` (16 to 1024px), `png/mono/` |
| Website | `web/`: `favicon.ico` (16, 32, 48), `favicon.svg`, `favicon-16/32.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `mask-icon.svg`, `site.webmanifest` |
| Dashboard tiles and app launchers | `png/rounded/` or `png/circle/` at the tile size |
| Android launcher icon (adaptive) | `android/res/`: `drawable/ic_launcher_{background,foreground,monochrome}.xml` and `mipmap-anydpi/ic_launcher{,_round}.xml`. Copy into `app/src/main/res/` |
| Android, pre-adaptive launchers | `android/legacy-mipmaps/mipmap-*/ic_launcher{,_round}.png` |
| Google Play listing | `android/play-store-512.png` |

## Android notes

The adaptive icon puts the sky and sea in the background layer and everything else in the
foreground. All of the mark sits inside the centred 66dp safe zone, so any launcher mask
(circle, squircle, teardrop) keeps it whole. The monochrome layer is used for Android 13+
themed icons. The vector drawables use `aapt:attr` gradients, which need API 24 or later.
